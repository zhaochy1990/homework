# 小程序信息架构与页面流 v1

> 产出自 wayfinder ticket「Prototype: 小程序信息架构与页面流」。低保真可点击原型：`docs/prototype/ia-prototype.html`（内含 A/B/C/D 四个变体，**D 为定稿方向**，其余保留供回溯）。上游依据：`docs/design/api-contract.md`、`docs/design/homework-parsing.md`、`docs/adr/0002`（班级共享/孩子私有）。

## 1. 底部 Tab（四个）

| Tab | 内容 |
|---|---|
| **今日** | 当天要做的事：孩子切换 + 分科作业卡（勾选、打卡） |
| **成长** | 走得怎么样：孩子切换 + 打卡日历 + 打卡动态 |
| **资料库** | 老师发的学习资料：班级切换 → 科目教材 → 单元 → 资料 |
| **我的** | 个人、孩子管理、班级管理入口、监护人邀请、上学日历、设置 |

Tab 排布逻辑：日常三件事（做作业、看成长、翻资料）各占一级；班级管理（发作业、成员、教材、解散）是低频动作，收进「我的」。微信小程序 Tab 上限 5，v1 用 4。

## 2. 页面清单与层级

```
Tab: 今日 ── 打卡弹层（附件）── 打卡成功 ── 打卡卡片
Tab: 成长（日历 + 动态，同屏上下结构）
Tab: 资料库 ── 单元列表 ── 单元资料 ── 视频播放/图片查看（全屏弹层）
Tab: 我的 ─┬ 班级列表行 → 班级详情（作业|资料|成员|教材 页签）── 发作业（粘贴→解析→确认）
           ├ 我的孩子 → 孩子管理（改名/头像/监护人邀请）
           └ 监护人邀请 / 上学日历 / 设置（二级页）
```

## 3. 各页面要点

### 3.1 今日
- 顶部孩子切换 chip（多孩家庭无隐式当前孩子）；日期行「N 科有作业 · 已打卡 N 科」；
- 每科一张通栏作业卡：科目名 + 合计预估时长（`≈35 分钟`，无估算不显示）+ 待办勾选列表（**条目级不显示时长**）+ `0/2` 进度 + 「打卡」按钮（全部勾选才启用）；
- 老师备注以「老师还提到」黄条展示在待办之下；
- 今日无作业的科目显示置灰行（家长一眼知道"没漏看，是真没有"）。

### 3.2 打卡弹层（发媒体的唯一入口）
- 从空开始：网格里只有 `＋` 格 → `wx.chooseMedia`（现场拍摄或相册多选，照片/视频混选，**合计 ≤ 9**）→ STS 直传 → confirm；
- 每个附件单独过 `mediaCheckAsync`（先审后显不影响本次打卡，仅影响他人可见性——v1 打卡附件本就仅监护人可见）；
- 可不附任何媒体直接打卡；
- **不设独立的"发照片/视频"入口**：附件离开"某天某科打卡"的上下文没有归属，v1 不做草稿箱。

### 3.3 成长
上下两个区块，同屏滚动：

**打卡日历**
- **一张全科目日历**，不按科目切换；
- 默认**当前周**，底部小箭头点开展开整月、箭头翻转向 上，再点收起；
- 日期格 = 日期数字 + 各科目**符号行**：形状=科目（● 语文 ▲ 数学 ■ 英语 ◆ 科学，新科目续其他形状），颜色=状态（绿=已打卡，红=漏卡）；周末显示「休」不挂符号（无义务不加不断），无作业日橙色标记，未来日期留白；
- **日期可点**：点某天 → 底部动态只显示那天的打卡（格子描边高亮，动态标题行出现 `9月21日 ✕` 筛选 chip）；再点同一天或点 chip 取消。

**打卡动态（朋友圈式）**
- 每条：孩子头像 + 昵称 + 科目 chip + 日期 + 家长一句话（可空）+ 三列媒体九宫格（视频块带 ▶ 时长）+ 「打卡卡片 ›」直达该次海报；
- **默认只显示最近 3 条，滚动到底自动加载**（对应 `GET /checkins` 的 offset 分页）；全部加载完显示"已经到底啦"；
- 点选日历日期后只显示那天的记录；该日无记录显示空态；
- 仅监护人可见，无点赞评论；
- **不设独立的卡片墙**——海报从每条动态进出。

### 3.4 资料库
- 顶部班级切换 chip → 按科目列教材卡（`语文 · 部编版一年级上册 · 4 个单元`）→ 单元列表 → 单元内资料（视频/图片/文本）；
- 未选教材的科目给"去选择"引导（跳班级详情教材页签）；
- 播放/查看走预签名 GET URL（1~2h，Range 原生支持）。

### 3.5 我的 / 班级详情
- 我的：个人资料卡 → **我的班级**（班级行：名称 + 谁在班 + 我的角色）→ 我的孩子 → 加入班级 → 监护人邀请 / 上学日历 / 设置；
- 班级详情四个页签：**作业**（今日/昨日分科列表 + 标记无作业日 + 管理员「发作业」「补录/追加」）、**资料**（同资料库内容，管理员发完作业顺手传）、**成员**（名单 + 加入审批 + 邀请码/小程序码）、**教材**（按科目选用/更换）。

### 3.6 发作业（管理员，入口在班级详情）
粘贴原文（可混科）→ 解析中 → 确认页（按科目分组、新建/追加标记、"老师还提到"可编辑）→ 入库。完整规格见 `docs/design/homework-parsing.md`。

## 4. 视觉基调

**全局扁平化**：区块通栏贴边、无卡片边框无圆角、发丝线分隔、直角按钮；只保留 16px 内部文字呼吸位；媒体缩略块是唯一的圆角对象。低保真阶段不设品牌色板，微信绿 `#07C160` 仅作主操作色。

## 5. 与既有规格的联动修订（本 ticket 落实）

| 规格 | 修订 |
|---|---|
| `CONTEXT.md` | 「打卡视频」→「**打卡附件**」（照片/视频，≤9） |
| `data-model.md` | `Checkin.VideoCosKey/VideoSecStatus` → `Checkin.Note` + 新表 `CheckinMedia`（type/cos_key/thumb_key/sec_status） |
| `api-contract.md` | checkin 入参 `{videoUploadId?}` → `{note?, media?: [{uploadId}]}`；upload-ticket kind `checkin_video` → `checkin_media`；打卡日历返回改为**每日 × 各科目状态** |
| `homework-parsing.md` §7 | 待办行不再显示条目级时长，仅分科合计 |

## 6. 被否决的备选（记录在案）

- 资料库收进班级（入口三层，与使用频率不符）；
- 今日页顶部 streak 摘要卡、每科 streak 徽章（进度全部归成长页）；
- 各科连续打卡进度条卡（streak 数字只保留在海报上）；
- 打卡卡片墙（海报从动态逐条进出）；
- 「加载更早」翻页按钮（改滚动自动加载）；
- 独立的发媒体/素材箱入口（附件随打卡）。
