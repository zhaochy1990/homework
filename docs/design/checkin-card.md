# 打卡卡片海报设计 v1

> 产出自 wayfinder ticket「Prototype: 打卡卡片海报设计」。视觉稿：`docs/prototype/card-prototype.html`（三版全保留，全部采用）。
> 用户决策：**三套模板不做单选，每次打卡随机用一套**。鼓励语保留（固定文案池轮换）；小程序码保留（分享回流）。

## 1. 总则

- **画布**：750 × 1000 px PNG（3:4 竖版），RGB。
- **模板**：三套 —— `medal`（奖牌风）/ `certificate`（证书风）/ `journal`（手账贴纸风）。
- **模板选择**：`seed = checkin.ID % 3` —— 确定性随机，同一打卡重试生成**同一张**（幂等），且三套长期均匀分布。
- **生成时机**：打卡事务提交后异步（Go goroutine + 重试队列）；失败不阻塞打卡，`checkin_cards` 无记录时客户端显示"生成中"并轮询。
- **技术选型**：`fogleman/gg` 绘制；字体 `go:embed` 随包分发——**站酷快乐体**（ZCOOL KuaiLe，标题/装饰）、**思源宋体**（Noto Serif SC，证书风正文）、**思源黑体**（Noto Sans SC，数字/日期/待办），三者均为 OFL 授权，可商用可再分发。
- **小程序码**：`wxacode.getUnlimitedQRCode`（scene 携 checkin 短标识），生成一次后缓存于 COS 复用；每模板按 §4 尺寸圆角底贴入。

## 2. 内容槽位与数据来源

| 槽位 | 来源 | 说明 |
|---|---|---|
| 孩子名 | `children.name` | |
| 日期 | `checkin.checkin_date`（CST）+ 星期 | "9月23日 周二"；证书风用"2026年9月23日 · 星期二"全格式 |
| 科目 | `session.subject` | 全局枚举（ADR 0007） |

| 完成待办 | 该 session 全部 `todo.content` | 能打卡即全部已勾，按 `sort_order` |
| 鼓励语 | 模板文案池 | 见 §3 各模板；`pool[checkin.ID % len(pool)]` |

| ~~家长一句话~~ | 不上海报 | 卡片是成绩单不是通知栏（012 定）；附件照片也不上海报 |

## 4. 生成管线（实现规范）

```
打卡事务提交
  → 异步任务（重试 3 次，间隔递增）
  → 组装槽位数据（§2；streak 取事务后值）
  → seed = checkin.ID % 3 选模板
  → gg 绘制 750×1000（字体 embed；QR 从 COS 取缓存）
  → PNG → 上传 COS `checkin-cards/{checkinID}.png`
  → 写 checkin_cards（幂等：按 checkin_id 唯一约束）
  → 失败：任务表重试；客户端 GET /checkins/{id}/card 轮询至就绪
```

- 同一打卡重试必须产出同一张（seed 确定性 + 待办列表当时快照，todo 后续编辑不重绘历史卡片——数据模型矩阵 #1）。
- QR 失败时降级：该位置留品牌名，不阻塞整卡生成。
- 大数字使用 `tabular` 数字字形，避免 1 与 4 宽度抖动。
