作业打卡小程序 v1
信息架构原型

四个 IA 变体（D 是按你反馈新改的），同一个手机里切换。对着结构反应，别管美观——这是线框。

怎么用

  • 手机里的灰色元素大多可以点：勾选、打卡、切 Tab、进班级、看资料。
  • 底部黑条或键盘 ← → 切换 A / B / C / D 四个变体（默认 D）。
  • 每个变体里把三条验收流程各走一遍（右侧清单），感受入口深浅。

三条验收流程

  1. 发作业（管理员）：进班级 → 一年二班 → 发作业 → 粘贴原文 → 解析 → 确认页（分科分组、追加标记、"老师还提到"）→ 入库
  2. 今日打卡：今日 → 勾完某科全部待办 → 打卡 →（可选视频）→ 打卡卡片
  3. 按单元看资料：进到教材单元 → 播视频 / 看图 / 读文字

已定（按你的反应）

  • 成长是一级 Tab——打卡日历 / 连续天数 / 卡片墙放「成长」。
  • 班级收进「我的」——三 Tab：今日 / 成长 / 我的（变体 D）。
  • 待办行不显示条目级时长，只保留分科合计。

还剩三个确认

  1. 资料入口深度：D 里看资料要走 我的 → 班级 → 资料 → 单元（三层）。可接受？还是要给捷径（比如今日页底部放"最新资料"两三条）？
  2. 今日页密度：D 沿用 B 的摘要式（顶部一张"最长连续 ×N"卡，点了去成长），还是想要 A 的每科 streak 徽章？
  3. 定稿：三条流程在 D 里再走一遍，顺了我就把结论落进 docs/design/ia.md 关闭本 ticket。
