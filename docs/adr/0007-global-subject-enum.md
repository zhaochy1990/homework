# 科目是全局封闭枚举

语文／数学／英语／物理／化学／生物／历史／地理／道法／科学／体育／艺术／其他——这份列表写死在代码里，是科目取值的唯一来源；班级不能自定义、不能新增、不能改名。原因不在界面而在数据：连续打卡天数（Streak）按**孩子 × 科目**聚合，且跨班同科目同日只计一次（ADR 0004），科目名一旦漂移（"数学" / "数 学" / "数学课"），同一条 streak 会分裂成互不相干的多条，且无从回补。替代方案"班级自维护科目集合"被否决：它多出一处需要与教材选用、历史 Session 持续对账的状态，换来的只是每班少看几个用不上的选项；而全局枚举下前端按"本班近 30 天出现过的科目"排序展示，选择成本几乎为零。代价是小学与初中共用一份列表，"物理""化学"等条目在多数班里长期闲置——可接受。
