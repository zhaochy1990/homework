## Question

小程序 v1 的信息架构需要定型：底部 tab 结构（候选：今日作业 / 班级 / 资料库 / 我的）、页面清单与跳转关系、三个核心流程的线框——①发作业（选科目→粘贴→解析确认）、②今日打卡（勾选→打卡→视频上传→卡片）、③按单元浏览资料（看图/播视频）。多孩、多班的视图聚合方式（"今日"是跨班聚合还是按班切换）也在此定。

产出：用 /prototype 做低保真可点击原型或页面流图，用户反应后把定稿截图/结论记入 `docs/design/ia.md`。

## Resolution

产出 `docs/design/ia.md`（信息架构定稿）+ 可点击原型 `docs/prototype/ia-prototype.html`（A/B/C/D 四变体，D 为定稿，含九轮用户反应迭代，全部提交在 main）。规格联动修订已落入 CONTEXT.md / data-model.md / api-contract.md / homework-parsing.md。

**定稿 IA：四 Tab（今日 / 成长 / 资料库 / 我的）**

- **今日**：孩子切换 + 分科作业卡（勾选、合计时长、打卡按钮）；无作业科目显示置灰行。
- **成长**：一张全科目打卡日历（默认周视图、箭头展开整月；日期格挂科目符号 ●语文 ▲数学 ■英语 ◆科学，绿=已打卡红=漏卡；**点日期筛选动态**）+ 朋友圈式打卡动态（头像/科目chip/家长一句话/九宫格媒体；**默认 3 条滚动到底自动加载**；每条「打卡卡片 ›」；仅监护人可见）。
- **资料库**（一级 Tab，学习时高频使用）：班级切换 → 科目教材 → 单元 → 资料；班级详情保留资料页签。
- **我的**：孩子、班级管理（发作业/成员/教材）、邀请、设置；班级从 Tab 降为我的里的入口。

**关键交互决策**（用户逐轮确认）：
1. 班级收进「我的」——低频管理动作不占一级（用户提出）。
2. 资料库升一级 Tab——"每次学习都可能用到"，频率决定层级（用户提出）。
3. 打卡附件：照片/视频混选、合计 ≤9、**无独立发媒体入口**（入口即打卡弹层的 ＋，弹层从空起步逐个添加）。
4. 日历单张化：科目用形状区分、颜色表达状态；周视图默认收起；点日期即筛选底下动态——日历是历史导航索引，动态首屏恒短。
5. 打卡卡片墙删除——海报从每条动态进出；「加载更早」按钮改滚动自动加载。
6. 待办行不显示条目级时长（估算值伪装精确），仅分科合计。
7. 全局扁平化视觉：通栏无边框、发丝线分隔、直角按钮（用户提出）。

被否决的备选记录在 `docs/design/ia.md` §6。
