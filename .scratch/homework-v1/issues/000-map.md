# 作业打卡小程序 v1 · Wayfinder 地图

## Destination

一份可交付实施的 **v1 规格书**：领域模型与表结构、API 契约、小程序页面流、关键集成方案（STRIDE 认证对接、COS 直传、DeepSeek 作业解析、微信内容安全）全部敲定，足以直接拆出实施 ticket 开写代码。规格敲定即到达——写代码是下一个 effort。

## Notes

- **领域词汇**：见根目录 `CONTEXT.md`（打卡/勾选/Session/待办等有严格区分，写文档前先读它）。
- **已定架构决策**：见 `docs/adr/0001`–`0007`（monorepo、班级共享/孩子私有边界、待办 id 不可变、streak 履约模型、COS 直传、STRIDE 认证复用、全局封闭学科枚举）。
- 技术栈：小程序 TS（`miniprogram/` 模板已在）+ Go/MySQL/GORM（`backend/`，开发期本地 MySQL）；生产腾讯云，复用备案域名与 auth-service 同环境。
- HITL ticket 的对话用中文。
- **本地 markdown tracker 约定**（本仓库的 Wayfinding operations）：
  - issue = `.scratch/homework-v1/issues/` 下的 markdown 文件，frontmatter 含 `id`、`title`、`labels`、`status`（open/closed）、`assignee`、`blocked-by`（依赖的 ticket id 列表）；
  - 地图 = `000-map.md`（本文件）；ticket 指针追加进本文件 "Decisions so far"；
  - **认领** = 把 `assignee` 写为当前驱动者，开工前先写；
  - **阻塞** = `blocked-by` 中所有 ticket 均为 closed 才可认领（frontier = open ∧ unassigned ∧ 无未闭合阻塞）；
  - **关闭** = `status: closed` + 在 ticket 末尾追加 `## Resolution` 记录答案，并在地图 "Decisions so far" 追加一行指针。

## Decisions so far

- [Research: DeepSeek API 现状与作业解析约束](004-research-deepseek-api.md) — 用 `deepseek-chat`（默认）+`deepseek-reasoner`（难例），模型名走配置；JSON mode 无 schema 强制，Go 侧严格校验+重试，降级终点为原文存库人工拆条（细节见 docs/research/004）
- [Research: 2026–2027 法定节假日与调休表](005-research-school-calendar.md) — 网络受限，仅产出**未核实草稿**：规则可推导的 2026 假日日 13 条（verified:false），调休补班日全部留空宁缺毋假；⚠️ 种子数据须经用户对照国务院公告核验后才能导入（细节见 docs/research/005）
- [Research: STRIDE 认证服务对接契约](001-research-stride-auth.md) — 登录=`POST /oauth/token` grant_type=token_exchange（subject_token=wx.login code）；JWT RS256，公钥走 `GET /api/system/public-key`（无 JWKS），消费方自校验 aud；refresh 一次性轮换 30 天滑动；需为新小程序注册 application；⚠️ ADR 0011/0010 的实现不在本地源码快照中，对接前需确认部署版本（细节见 docs/research/001）
- [Research: 微信内容安全 API 接入要点](002-research-wechat-content-security.md) — 文本走 `msgSecCheck` 同步（v2 必传 openid），图片/视频走 `mediaCheckAsync` 异步、结果经消息推送 `wxa_media_check` 事件（trace_id 幂等）；先审后显：pending/blocked 对成员不可见；Go 自写薄封装 + stable_token 集中缓存；配额数字需提审前验证（细节见 docs/research/002）
- [Research: 小程序媒体上传与 COS 直传/播放](003-research-cos-direct-upload.md) — 上传选型 A：**STS 临时密钥 + cos-wx-sdk-v5 分片直传**（预签名 PUT 与 wx.uploadFile multipart 不匹配且无法分片）；播放/查看用后端预签名 GET URL（Range 原生支持）；上传确认=确认端点+后端 HEAD 校验；封面用 chooseMedia 的 thumbTempFilePath；CAM 上传角色仅写 uploads/ 前缀（细节见 docs/research/003）
- [Grilling: 数据模型与状态机](010-data-model.md) — 17 张表 GORM 定义落定（`docs/design/data-model.md`）；履约义务定义（迟建不追溯断签）、streak 事件驱动计数器+惰性中断+每日校准、打卡即冻结勾选、操作影响矩阵 10 条、时区 CST 硬编码；011/012 已解除阻塞
- [Grilling: API 契约设计](011-api-contract.md) — `/api/v1` 契约定稿（`docs/design/api-contract.md`）：本地验签含 aud 自校验、错误形状对齐 auth-service、9 组端点 + 18 个稳定错误码、上传走 upload-ticket+confirm、LLM 解析同步、班级 join_approval 审批开关（端点统一为 POST /join-requests）；data-model 回填 join_approval+申请表
- [Grilling: LLM 作业解析与确认流设计](012-llm-parsing-flow.md) — 支持**混科解析**（schema 精简为 `{subject, content, estimated_minutes}`，`unparsed`→`homework_sessions.notes`）；确认页只做增删改序**不做合并/拆分**；失败→重试（同模型同 prompt，温度 0.3）→单学科多行文本框手填；入库单事务（msgSecCheck → 判 kind → 冲突校验 → 写），支持**追加到已有 Session**；学科收紧为全局封闭枚举（ADR 0007）（细节见 docs/design/homework-parsing.md）

## Not yet specified

- **隐私与未成年人内容合规**：孩子打卡视频的保存期限、删除权、监护人授权话术；提审可能被问。
- **视频封面/首帧/转码**：COS 数据万象（CI）是否引入，依赖媒体上传研究 ticket 的结论。
- **部署与发布流程**：是否复用 stride-devops 的 GitOps（镜像 → pin PR）流程部署作业后端。
- **教材库内容治理**：v1 无审核直接可加，出现垃圾内容后的收紧策略。
