# 作业打卡小程序 v1 · Wayfinder 地图

## Destination

一份可交付实施的 **v1 规格书**：领域模型与表结构、API 契约、小程序页面流、关键集成方案（STRIDE 认证对接、COS 直传、DeepSeek 作业解析、微信内容安全）全部敲定，足以直接拆出实施 ticket 开写代码。规格敲定即到达——写代码是下一个 effort。

## Notes

- **领域词汇**：见根目录 `CONTEXT.md`（打卡/勾选/Session/待办等有严格区分，写文档前先读它）。
- **已定架构决策**：见 `docs/adr/0001`–`0006`（monorepo、班级共享/孩子私有边界、待办 id 不可变、streak 履约模型、COS 直传、STRIDE 认证复用）。
- 技术栈：小程序 TS（`miniprogram/` 模板已在）+ Go/MySQL/GORM（`backend/`，开发期本地 MySQL）；生产腾讯云，复用备案域名与 auth-service 同环境。
- HITL ticket 的对话用中文。
- **本地 markdown tracker 约定**（本仓库的 Wayfinding operations）：
  - issue = `.scratch/homework-v1/issues/` 下的 markdown 文件，frontmatter 含 `id`、`title`、`labels`、`status`（open/closed）、`assignee`、`blocked-by`（依赖的 ticket id 列表）；
  - 地图 = `000-map.md`（本文件）；ticket 指针追加进本文件 "Decisions so far"；
  - **认领** = 把 `assignee` 写为当前驱动者，开工前先写；
  - **阻塞** = `blocked-by` 中所有 ticket 均为 closed 才可认领（frontier = open ∧ unassigned ∧ 无未闭合阻塞）；
  - **关闭** = `status: closed` + 在 ticket 末尾追加 `## Resolution` 记录答案，并在地图 "Decisions so far" 追加一行指针。

## Not yet specified

- 数据模型落地后的**操作影响矩阵**：补录/编辑/删除作业、标记/取消无作业日 对 已有打卡与 streak 的完整影响（等数据建模 ticket 收敛后可能拆成细则 ticket）。
- **隐私与未成年人内容合规**：孩子打卡视频的保存期限、删除权、监护人授权话术；提审可能被问。
- **视频封面/首帧/转码**：COS 数据万象（CI）是否引入，依赖媒体上传研究 ticket 的结论。
- **部署与发布流程**：是否复用 stride-devops 的 GitOps（镜像 → pin PR）流程部署作业后端。
- **教材库内容治理**：v1 无审核直接可加，出现垃圾内容后的收紧策略。

- CDN；
- 手机号+验证码登录的小程序 UI（能力保留在认证服务）；
